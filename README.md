### Giovanni De Lucia

[**TimberStrike**](https://doi.org/10.56553/popets-2025-0145) (PoPETs 2025) shows that a single honest-but-curious client can reconstruct other participants' training data from federated gradient-boosted trees ([code](https://github.com/necst/TimberStrike)).
